Research

SuperEEG, Brought Up to Date

Python | GPyTorch | github.com/benolivr/supereeg-gpyt

SuperEEG estimates activity throughout the brain from a small number of implanted electrodes. It learns how activity at different locations correlates across many patients, then uses Gaussian process regression to fill in the places nobody recorded. It was my advisor's doctoral project. I ported it to GPyTorch so model building can run on the GPU, moved it to modern Python (3.12+, NumPy 2), and added a tool that converts files saved in the old format.

Archetypal Analysis of Brain Activity

I'm investigating archetypal analysis as a way to describe brain activity. Common ways of compressing brain data, like PCA, produce components that can be hard to read, since they mix positive and negative contributions. Archetypal analysis instead describes each moment as a blend of a few extreme patterns that actually appear in the data, which makes it easier to ask what each pattern means.

Brain Dynamics After Trauma

Early stage

Next, I'm looking at combining archetypal analysis with timecorr, which measures how brain regions rise and fall together moment by moment, and how that coordination itself shifts. The plan is to apply both to fMRI from trauma-exposed people, to see whether exposure leaves a shared signature in how the brain coordinates itself, and whether people who go on to struggle, stay resilient or recover look different.
